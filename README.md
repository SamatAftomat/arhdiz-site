# Арх.Диз — сайт

Одностраничный сайт для **Арх.Диз** — архитектурного бюро в Таганроге: проекты
частных домов, дизайн-проекты интерьеров, благоустройство участков и перепланировки.

- Данные: карточка [2ГИС](https://2gis.ru/taganrog/firm/70000001052919633) —
  5,0 ★, 10 оценок, 10 отзывов, 215 фото, контакты, прайс, рубрики, оплата
- Статический сайт: HTML + CSS + JS, без сборки
- Стиль: «Сигнальный чертёж» (Unbounded + Manrope) — как у сайтов 01–08

  горизонтальные рендеры среди 215 фото
